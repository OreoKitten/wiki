☁️ Hosting Your Wiki Hub: GitHub Pages vs. Cloudflare Pages (Or Both!)

      

        Because this hub and your subfolder wikis are 100% static files using relative paths (./AITZA/index.html), you can host the exact same OreoKitten/wiki repository on both GitHub Pages and Cloudflare Pages simultaneously with zero code changes.
      


      

        

          

            
🐙 Option A: GitHub Pages

            Zero Setup • Built into GitHub
          

          
    
            
  1. Open github.com/OreoKitten/wiki → Settings → Pages.
    2. 
            
  2. Under Build and deployment → Source, select Deploy from a branch.
    3. 
            
  3. Select branch main and folder / (root), then click Save.
    4. 
            
  4. In ~60 seconds, your hub is live at https://oreokitten.github.io/wiki/ and your first wiki is at https://oreokitten.github.io/wiki/AITZA/.
    5. 
          

        


        

          

            
⚡ Option B: Cloudflare Pages

            Unlimited Bandwidth • Global Edge
          

          
    
            
  1. In Cloudflare Dashboard, go to Workers & Pages → Create → Pages → Connect to Git.
    2. 
            
  2. Select your OreoKitten/wiki repository and branch main.
    3. 
            
  3. Leave Build command empty and set Build output directory to /.
    4. 
            
  4. Deploy! Cloudflare automatically serves index.html at root and /AITZA/ for your subfolder.
    5.
