## 6. Fang Heng's Zombie Clone & Proliferator Reference Table (Levels 1–70)

### Mathematical Rules Verified from the Novel
- **Levels 1–10 (Base SSS Talent — *Enhanced Super Zombie Clone*, Ch. 2)**: At Level $n$, Fang Heng gains $n$ zombie clones. Cumulative total at Level $n$ is $\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$, reaching **55 zombie clones** at Level 10 (Ch. 76).
- **Levels 11+ (Stage 1 SSS Talent Enhancement — *Rapid Growth*, Ch. 113)**:
  - **Enhancement Effect 1 (+20% Exponential Scaling)**: Every level-up grants an additional 20% of the current base zombie clones, rounded up: $\text{Total}_{n} = \lceil \text{Total}_{n-1} \times 1.2 \rceil$, and $\text{Gained}_{n} = \text{Total}_{n} - \text{Total}_{n-1}$. Proliferators do not count toward the base 20% calculation.
  - **Enhancement Effect 2 (6-Hour Proliferation)**: Outside combat, each base zombie clone generates 1 **Proliferator** every 6 hours, up to **3 Proliferators** per base clone after 18 hours. Thus, $\text{Total Army (with Proliferators)} = \text{Base Clones} \times 4$.
